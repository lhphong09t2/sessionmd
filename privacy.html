Privacy Policy — SessionMD Chrome Extension

Last Updated: 2026-11-22 · Publisher: FlowBench Lab

Zero Page Scraping No <all_urls>, activeTab, or scripting permissions
100% Local Storage Workspaces & crash snapshots stay on your device
Zero Telemetry SDKs No analytics, cookies, ad pixels, or session uploads

1. Zero Page Scraping, Zero Telemetry

SessionMD is a 100% local Chrome Manifest V3 session and tab manager. SessionMD uses strictly scoped browser APIs (storage, tabs, tabGroups, and alarms) plus narrow host_permissions (https://api.polar.sh/*, used solely when an optional Pro license key is activated or revalidated) — with zero <all_urls>, website host access, activeTab, or scripting permissions. It never reads webpage DOM contents, cookies, or browsing history, and never transmits your open tabs, titles, or URLs to any developer server or analytics endpoint.

2. Local Browser Storage (chrome.storage.local)

SessionMD stores data strictly inside your local browser profile:

  1. Saved Workspaces (sessionmd_workspaces_v1): Tab sessions and Chrome tab group metadata you explicitly choose to save. You can update, export as JSON/Markdown/CSV, or delete any workspace at any time.
  2. Crash-Safe Auto-Snapshots (sessionmd_crash_snapshots_v1): A rolling local ring buffer (up to 12 snapshots) captured periodically by local alarms to help you recover tabs after unexpected browser restarts.
  3. Pro License State (sessionmd_pro_license_v1): Optional Polar.sh license key, activation ID, and last validation timestamp used solely to support 12-hour revalidation and a 7-day offline grace window.

3. Optional License Validation (https://api.polar.sh)

If you choose to activate a SessionMD Pro license key ($29 one-time purchase), SessionMD sends only your entered license key, the FlowBench Lab Polar organization identifier, and the extension activation label over HTTPS directly to Polar.sh (https://api.polar.sh/v1/customer-portal/license-keys). Free users who do not enter a license key trigger zero outbound network requests.

4. Data Sale & Tracking Declaration

  • We do not sell, rent, or transfer user data to third parties.
  • We do not use remote code, tracking pixels, cookies, telemetry, or advertising SDKs.
  • We do not use user data for purposes unrelated to SessionMD's single tab-session and workspace management purpose or for creditworthiness/lending.

5. Chrome Web Store Permission Summary

  • tabs + tabGroups: Reads open tab URLs, titles, pinned state, and Chrome Tab Group labels/colors strictly to save, deduplicate, search, and restore your browser sessions locally. Never accesses webpage DOM contents.
  • storage: Stores saved workspaces, up to 12 crash-recovery auto-snapshots, and optional Polar Pro license activation state strictly on your device.
  • alarms: Triggers periodic local crash-safe auto-snapshots (every 15 minutes) and 12-hour license revalidation when a Pro key is active.
  • host_permissions (https://api.polar.sh/*): Used solely when an optional SessionMD Pro license key is activated or revalidated over HTTPS with Polar.sh; Free users trigger zero outbound network requests, and SessionMD requests zero <all_urls> or website host access.
